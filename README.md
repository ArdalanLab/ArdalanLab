# Ardalan Alizadeh

Medical laboratory scientist (B.Sc. Laboratory Sciences, Kashan University of Medical Sciences) based in Isfahan, Iran. I work on immunology, immunological tolerance and omics data analysis, and I'm applying for research-oriented Master's programs in molecular life sciences.

- Computational: Python (pandas, BioPython) and R for sequence and repertoire analysis
- Co-author: Mousavi MJ, Alizadeh A, Ghotloo S. *Interference of B lymphocyte tolerance by prolactin in rheumatic autoimmune diseases.* Heliyon 9(6), e16977 (2023). [doi.org/10.1016/j.heliyon.2023.e16977](https://doi.org/10.1016/j.heliyon.2023.e16977)

## Projects

- **[AVY motif retention in IGHV4-34 antibodies in SLE](https://github.com/ArdalanLab/ighv4-34-avy-sle)**: exploratory analysis of public OAS repertoire data from 7 SLE patients. In all 7, the self-reactivity motif AVY is retained less often in IgG than in IgM, with clone-aware bootstrap intervals and unit-tested code. A mutation-load analysis is in progress.
- **[Protein phylogenetic tree](LINK-TO-REPO)**: protein sequence distance analysis and UPGMA tree construction with BioPython.
- **[Sequence analysis toolkit](LINK-TO-REPO)**: parsing, format conversion and alignment utilities.
